# Carpal Tunnel Release Source Gap

Formal source completeness remains incomplete. It does not block draft creation
or multi-agent review, but disputed high-risk claims should receive targeted
evidence checks and publication still requires authorized human approval.

The repository contains educational facts derived from Miller and Orthobullets
datasets, plus a local carpal-tunnel anatomy record. The procedure registry,
however, has no approved source records identifying edition/date, supported
approach, relevant section or chunk, and review limitations.

Before publication-quality evidence completeness:

1. Register an authoritative hand-surgery or orthopaedic source for indications,
   contraindications, open release, postoperative care, complications, and
   failure analysis.
2. Register authoritative endoscopic guidance that is general enough to avoid
   unsupported device-specific instructions.
3. Link each extracted claim to a source identifier and section/chunk.
4. Record conflicts and preference-sensitive recommendations.
5. Obtain attending hand-surgeon review of both the source inventory and
   generated content.

A structured draft and two-wave review package may exist while this gap remains
open. No certification or runtime publication may occur without the independent
review gates, deterministic QA, exact hash binding, and authorized attending
approval.
